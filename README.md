# Eric Ormstead — Personal Portfolio

Source for [Eric Ormstead's public portfolio](https://eric-ormstead-portfolio.eric-m-ormstead.chatgpt.site).

The site presents Eric's decade-plus Office Depot engineering foundation and his progression into Accenture technical and delivery leadership. It highlights enterprise delivery, Stibo STEP and product-data expertise, solution architecture, integrations, cloud technologies, and leadership under ambiguity.

## Stack

- React 19 and Next.js-compatible App Router
- Vinext and Vite
- Cloudflare Workers deployment output
- Tailwind CSS

## Local development

Node.js 22.13 or newer is required.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The public production site is hosted through OpenAI Sites. This repository is the reviewable source of truth for the portfolio.
